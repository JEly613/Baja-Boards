# Baja-Boards
My work with Hopkins Baja

## Main Peripheral Board

Purpose:
- 15 pin hub for routing usb, can, and ethernet signals from the main board to external components.
- Station for a status light to indicate state of main board
- Switch between Teensy and ESP USB signals on main
